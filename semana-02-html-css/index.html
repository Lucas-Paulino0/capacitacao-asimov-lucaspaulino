CivilCore Em desenvolvimento

Mod de civilização para Minecraft que adiciona um Mural de Comércio: jogadores publicam pedidos de compra, ofertas de venda e serviços, negociam propostas e registram contratos assinados num item próprio. Os dados ficam salvos no servidor e são sincronizados entre os jogadores. Imagem do conceito da interface.

  • Java
  • NeoForge 1.21.1
  • Multiplayer (pacotes de rede)
